Atlas methods and source

The atlas displays spatial transcriptomics from the selected source Seurat objects. Dataset labels distinguish preparation, passage or condition, and biological material. Source objects are retained unchanged.

Spatial display

Regular Visium markers represent spots. Visium HD markers represent segmented-cell centers, not polygon boundaries. Each capture uses its matching histology image and spatial scale. Tissue outside the measured capture can appear without markers. Histology WebP files preserve the original image dimensions and pixels.

Expression and annotations

Expression values come from the assay and layer shown in the viewer, currently SCT/data. Sparse values are stored as float32 with zero-based uint32 cell indices. Missing entries within an available gene are zero; an unavailable gene is not treated as zero. Identity labels and UMAP coordinates come from each source object. UMAP layouts from different objects are not necessarily comparable.

The default expression maximum is the 95th percentile among cells with positive expression in the entire selected dataset. Values above that cutoff share the highest color. This changes display colors only. Use the same manual maximum for comparisons. Filtering a region does not change the automatic scale. Opacity applies to the complete marker layer, including overlapping markers.

Sharing and citation

Use “Copy link” to preserve the dataset, capture, region, gene, display mode, and manual expression maximum. For figures and reuse, record that link, the access date, and the source object and assay/layer shown in the viewer. A manuscript citation has not yet been specified for this atlas release; no publication reference is inferred.
